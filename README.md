# Biteary

Biteary is a SwiftUI-based iPhone application designed for recording food when travelling. The app allows for travellers to record the food they eat on vacation by providing a personal journal where they can input an image, other specific details and information regarding the dish. 


## Developers

This app was developed in the Apple Developer Academy by:
- Rodrigo Llaguno
- Vincenzo Picone

- Rezzan Tekinsen

## Features

- Create folders for specific trips or dates.
- Organize your folders.
- Add your foods and dishes into the folders.
- Input information about the dish, including photos!
- Remember the food you ate!
